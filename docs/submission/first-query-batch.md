## Current Recommendation

Start with **6 agents**, not 30. This is a signal-gathering batch. If there are no requests after 6-8 carefully chosen queries, adjust the query/opening before expanding.

Use **prologue-first** when the agent asks for 10+ pages or likes horror/speculative openings. Use **Rook-first** when the agent asks for very short pages, dislikes prologues, or emphasizes immediate protagonist attachment.
