# Submission Readiness Audit

Date: 2026-07-06

## Verdict

**Not quite send-now, but close.** The manuscript has a real voice, a clear emotional engine, and a strong enough ending to query after one more human read-aloud/copy pass. The biggest submission risk is no longer "AI smell." It is package confidence: title consistency, opening strategy, query positioning, and first-pages polish.

## What Works

- **Rook's voice is specific.** Body-math, hunger, ownership, hands, keys, wounds, names, and counting give the book a recognizable internal grammar.
- **The core hook is strong.** A formerly enslaved boy survives a death island, is adopted by monster-peoples, becomes their king, then is captured by humans and made property again.
- **Marrow and Kala land emotionally.** Their function is not decorative; they become the cost of Rook wanting anything.
- **Drevan/Yara are more interesting than simple slaver/victim roles.** Drevan is a reader of systems; Yara is compromised without becoming flat.
- **The ending turns captivity into momentum.** Rook does not win freedom, but he wins room, a map, and a sequel engine.

## Submission Risks

- **Prologue risk.** Chapter 1 is good, but it is not Rook. Some agents dislike prologues by default. If sample pages are limited to 5-10 pages, consider whether the query should submit Chapter 2 as page one and mention the cold open as optional.
- **Title inconsistency.** Older package files still used *Ice and Blood* and outdated chapter/word-count language. This pass corrected the front-facing README and book TOC, but older internal docs still contain historical titles.
- **Market framing.** "Dark fantasy" may undersell the book. The stronger shelf is adult epic fantasy with visceral literary prose and horror pressure.
- **First ten pages are readable but indirect.** The prologue opens with atmosphere and dread rather than protagonist desire. That can work, but only if the query makes the Rook engine obvious.
- **The manuscript is not copyedited.** It is coherent and much tighter, but a read-aloud pass would still catch rhythm repetitions and taste-level line issues.

## Recommended Opening Strategy

For agents who ask for only **5 pages**, test two versions:

1. **Default:** include Chapter 1 prologue if the agent likes dark/speculative openings, horror pressure, or high-concept fantasy.
2. **Rook-first:** start with Chapter 2 if the agent emphasizes voice, character attachment, or "no prologues."

For agents who ask for **10+ pages**, the prologue is safer because they will reach Rook quickly.

## Send / Don't Send

**Do not mass-query yet.**

**Do send to 3-5 carefully chosen test agents or trusted readers after:**

- one read-aloud pass on Chapter 1 and Chapter 2,
- one check that all query materials use one title and word count,
- a final decision on whether the submission sample starts with the prologue or Rook.

If those pass cleanly, the book is ready for a controlled first query batch.
